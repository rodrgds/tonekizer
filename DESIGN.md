# Tonekizer design

A compact game and score sheet, inspired by the immediate input-to-ranking flow of outbid.lol. Warm cream, dark green ink, restrained lime selection. Sora carries the word itself; DM Sans handles controls. The token fragments are the only colorful data display.

One column. Brand and rules, a two-line title, mode and token controls, input, live breakdown, inline nickname, leaderboard grouped by length. No account flow, sidebar, decorative cards, or daily countdown. Mobile stacks the submit action and keeps all boards accessible.

Controls use native buttons with pressed states, labeled inputs, visible focus, polite result announcements, and reduced-motion support. Empty leaderboards are real empty states, never invented scores.
